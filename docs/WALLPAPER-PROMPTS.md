# Wallpaper generation record

The two illustrated wallpapers were created from the reference images supplied by
the project owner. The transformation brief deliberately removes the character,
cards, lettering, logos, borders and any recognizable commercial mark; it keeps
only palette, texture, geometry, lighting and line rhythm. The other two themes
are CSS treatments and do not include downloaded artwork.

## Blueprint Clean

> Extract only the cool blue blueprint paper texture, thin technical construction
> lines, measured geometry, subtle grid, soft ink bleed and pale blue highlights
> from the supplied reference. Remove the joker/person, all cards, all text,
> letters, logos, borders and symbols. Generate a clean seamless 9:16 mobile
> wallpaper, quiet low-detail center, slightly denser blueprint marks near the
> edges, high contrast separation for cream UI text, no characters, no objects,
> no readable writing, no watermark.

## Brainstorm Clean

> Extract only the warm cream paper, red and blue marker strokes, translucent
> drafting layers, soft graphite traces and playful brainstorming geometry from
> the supplied reference. Remove the joker/person, all cards, all text, letters,
> logos, borders and symbols. Generate a clean seamless 9:16 mobile wallpaper,
> quiet low-detail center, edge-weighted sketch energy, no characters, no
> objects, no readable writing, no watermark, with a soft dark overlay zone for
> readable UI labels.

## Provenance and licensing

- Source: user-supplied reference images in the Codex attachment set; no web art
  was downloaded.
- Transformation: GPT Image image-edit workflow, with the removal constraints
  above.
- App treatments: `Balatro Main Menu` is a CSS-only red/blue/graphite treatment;
  `Graphite Solid` is a CSS-only flat color.
- The generated files are app UI assets for this project and are not a copy of
  Balatro game files or commercial game content.

## Asset variants

`blueprint-clean.png` and `brainstorm-clean.png` are the full-size assets used
by the WebView. The `*-1x.png` files are the reduced mobile variants. The app
adds a contrast layer in CSS rather than altering the wallpaper image.
